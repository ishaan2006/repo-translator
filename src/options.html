Repo Translator

Translates non-English READMEs, repo descriptions, issues and pull requests on GitHub into English with Claude. Code, commands and names are left untouched.

Anthropic API key

Stored only in this browser's local extension storage on this device. It is not synced to your Google or Firefox account, never shown to GitHub pages, and only ever sent to api.anthropic.com.

Tip: give this key a monthly spend limit in the Anthropic Console. To keep costs down, long pages are translated as you scroll, identical text is sent once, and every translation is cached on this device, so nothing is paid for twice.

Translation

Default claude-haiku-5-5 (fast and cheap). Use a Sonnet model for harder technical text.

Permissions

Firefox needs your OK to run on github.com and to reach api.anthropic.com.
